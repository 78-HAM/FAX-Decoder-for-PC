# FAX Decoder
BY MC_blone
一个基于 Python 的传真（Fax）信号实时解码器，可将音频中的传真信号（1500Hz ~ 2300Hz 频移键控）解调为灰度图像，支持实时声卡输入、音频文件解码、频谱显示、歪斜校准和手动纠错。

English documentation is available in [EN.md](EN.md).

## 功能特性

- **实时解码**：从声卡（麦克风 / 虚拟声卡 loopback）实时采集音频并解码
- **文件解码**：支持 WAV / FLAC / OGG / AIFF / AU / MP3 / M4A 等音频文件
- **频谱显示**：实时 FFT 频谱可视化，标注 1500Hz / 2300Hz 频段
- **图像保存**：PNG / JPEG / TIFF / 16 位 RAW 灰度图
- **音频录制**：可录制原始音频用于后续分析
- **歪斜校准**：两点式手动校正图像歪斜（skew）
- **起点校准**：拖动竖线设置扫描起点偏移
- **手动分段纠正**：对已经解码的图像分段独立设置偏移与斜度，并固化到历史数据
- **多转速支持**：30 / 60 / 120 / 240 / 480 RPM
- **对比度 / 二值化**：实时调整对比度并可输出纯黑白图像
- **缩放平移**：鼠标滚轮缩放，拖拽平移查看

## 工作原理

传真信号使用 **FSK（频移键控）** 调制：

| 频率 | 含义 |
|------|------|
| 1500 Hz | 白（低亮度） |
| 2300 Hz | 黑（高亮度） |

解码流程：

音频输入 -> 重采样(至60kHz) -> 按行分段 -> 逐像素 FFT 峰值检测
        -> 频率-灰度映射 -> 应用歪斜/偏移 -> 图像位图

程序对每一个像素窗口做 FFT，在 1500–2300Hz 范围内寻找谱峰，用抛物线插值细化频率，再线性映射为 0–255 灰度。

## 使用教程

### 1. 选择音频输入设备（实时解码）

菜单栏 -> **驱动** -> **设置…**

在弹出的列表中选择合适的输入设备：

- 解码麦克风拾取的音频：选择麦克风
- 解码系统播放的音频（如从 SDR、播放器输出的传真音频）：
  - Windows：**Stereo Mix** 或 **VB-Cable**
  - macOS：**BlackHole** / **Loopback**
  - Linux：**PulseAudio Monitor**

点击 **确定**。若不确定可先点 **重置** 使用系统默认设备。

### 2. 选择转速

菜单栏 -> **设置** -> **选择转速**

| 转速 | 每行时长 | 常见场景 |
|------|---------|---------|
| 60 RPM | 1.0 s | 标准气象传真 |
| 120 RPM | 0.5 s | 大多数无线电气象传真（默认） |
| 240 RPM | 0.25 s | 高速传真 |

> 转速选错会导致图像被拉伸或压扁。

### 3. 调整图像宽度

菜单栏 -> **设置** -> **设置图像宽度**（默认 2000 像素）

宽度一般对应原图每行的采样点数。若图像明显变形，可尝试调整。

### 4. 开始解码

#### 实时解码
1. 点击右侧 **开始解码** 按钮
2. 播放音频或对着麦克风播放传真信号
3. 观察频谱图中 1500–2300Hz 之间是否有能量
4. 完成后点击 **停止解码**

#### 文件解码
1. 菜单栏 -> **文件** -> **选择音频文件…**
2. 菜单栏 -> **文件** -> **开始文件解码**
3. 解码完成后会弹出提示

### 5. 图像校准

#### 歪斜校准（全局）
菜单栏 -> **设置** -> **校准歪斜 (全局)**

1. 在画布上找到一个**本应水平对齐的参考点**（如图像边缘的某个特征）
2. 拖动绿色十字到第 1 点，点击 **确定第 1 点**
3. 拖动红色十字到同一参考点在图像下方出现的位置
4. 点击 **应用校准**

#### 设置起点（全局）
菜单栏 -> **设置** -> **设置起点 (全局)**

拖动黄色竖线到图像内容实际起始位置，点击 **确定位置**。

#### 手动纠正（分段校准）
菜单栏 -> **设置** -> **手动纠正**

适用于图像某一段发生歪斜而其他段正常的情况：

1. **设置分割线**：在画布上拖动红色水平线选定分段位置
2. **设置偏移**：拖动黄色竖线调整下段起点
3. **设置斜度**：两点法测量下段歪斜
4. **确认应用**：将调整固化到历史数据

> 每一步都可通过 **手动调整** 打开精细化数值窗口，用按钮步进（左 / 右）或手动输入数值。

### 6. 调整对比度

菜单栏 -> **设置** -> **设置对比度**

- 拖动滑块调整对比度（0–500%）
- 勾选 **二值化** 输出纯黑白图
- 点击 **确定** 实时应用到全部历史图像

### 7. 保存图像

菜单栏 -> **文件** -> **保存图像…**

支持格式：

| 格式 | 说明 |
|------|------|
| PNG | 无损灰度（推荐） |
| JPEG | 有损压缩 |
| TIFF | 无损 |
| RAW | 16 位灰度，需配合宽度/行数打开 |

### 8. 录制音频

菜单栏 -> **录制** -> **打开录制面板**

1. 点击 **开始录制**，面板自动隐藏（录制中）
2. 再次从菜单打开面板
3. 点击 **结束录制**，弹出保存对话框

## 参数说明（源码顶部）

SAMPLE_RATE_LIVE  = 48000   # 声卡采样率
FFT_SIZE          = 2048    # 频谱显示 FFT 长度
F_MIN, F_MAX      = 1500, 2300  # FSK 频率范围 (Hz)
TARGET_SAMPLE_RATE = 60000  # 解码内部重采样目标
CHUNK_SIZE        = 1024    # 音频块大小
MAX_LINES         = 10000   # 最大图像行数

### 可调 UI 参数

- `self.image_width`：每行像素数（默认 2000）
- `self.seconds_per_line`：每行时长（默认 0.5s = 120 RPM）
- `self.contrast`：对比度倍率（默认 1.1）
- `self.is_binary_mode`：是否输出二值化图像
- `self.spectrum_decay_rate`：频谱衰减速度（0.1 ~ 0.99）
